# Código de conduta

Este repositório deve ser usado com respeito, responsabilidade acadêmica e colaboração profissional.

## Condutas esperadas

- Comunicar-se com clareza e respeito.
- Registrar os combinados importantes no repositório.
- Revisar as contribuições dos colegas com foco técnico e postura construtiva.
- Dar crédito às contribuições individuais e coletivas.
- Tratar as divergências com base em evidências e nos critérios do projeto.

## Condutas inadequadas

- Remover o trabalho de colegas sem alinhamento.
- Expor dados pessoais, credenciais ou informações sensíveis.
- Usar linguagem ofensiva ou discriminatória.
- Manipular o histórico para ocultar falta de participação.

## Encaminhamento

Os problemas de conduta devem ser comunicados ao professor responsável pela disciplina.
