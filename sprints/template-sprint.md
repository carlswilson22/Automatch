# Template de sprint

## Período

Informe a data de início e de fim da sprint.

## Objetivo

Resuma o principal resultado esperado para o período.

## Milestone

Indique a `milestone` do GitHub associada a esta sprint.

## Itens planejados

Liste as entregas, as tarefas ou as `issues` previstas para o ciclo.

## Responsáveis

Associe pessoas ou papéis aos principais itens planejados.

## Entregas

Registre os artefatos, os documentos, as funcionalidades ou os resultados produzidos.

## Issues concluídas

Liste as `issues` encerradas durante a sprint, com links ou identificadores.

## Pull requests aceitos

Registre os `pull requests` aceitos no período e o que cada um consolidou.

## Evidências

Inclua links para documentos, demonstrações, imagens, validações, históricos ou outros registros verificáveis.

## Impedimentos

Documente os bloqueios, os riscos materializados, as dependências ou os desvios relevantes.

## Retrospectiva

Registre os aprendizados, os pontos fortes, as fragilidades e os ajustes sugeridos para o próximo ciclo.

## Próximas ações

Liste os encaminhamentos, a preparação da próxima sprint e as pendências abertas.
