## 📌 Diretrizes de Documentação de Sprints

1. **Rastreabilidade**: Cada documento de sprint conecta o objetivo aos itens de backlog, commits no Git e evidências de validação.
2. **Evidências**: São consideradas evidências testes automatizados aprovados, tempo de build no Vite, prints de tela e logs de container.
3. **Novo Ciclo**: Para iniciar um novo ciclo, utilize o arquivo [`template-sprint.md`](template-sprint.md) como modelo padrão.
