## 📌 Diretrizes de Avaliação

Cada relatório de entrega preserva a rastreabilidade direta por evidências, incluindo:
1. **Links para artefatos e código**: Módulos implementados e rotas no backend/frontend.
2. **Suíte de testes automatizados**: Testes de integração e casos de uso de ponta a ponta.
3. **Métricas de compilação**: Tempo de build, redução de bundle JavaScript e conformidade de contêineres Docker.
4. **Governança**: Rastreabilidade com as histórias de usuário documentadas no [`BACKLOG.md`](../BACKLOG.md).
5. **Modelo**: Para novas submissões pontuais, consulte o [`template-entrega.md`](template-entrega.md).
