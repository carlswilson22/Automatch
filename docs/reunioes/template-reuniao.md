# Template de reunião

## Data

Registre a data da reunião no formato AAAA-MM-DD.

## Participantes

Liste os nomes e os papéis de quem participou.

## Pauta

Resuma os tópicos previstos para discussão.

## Decisões

Documente as decisões tomadas durante a reunião.

## Encaminhamentos

Liste as ações, os responsáveis e os prazos combinados.

## Impedimentos

Registre os bloqueios, os riscos ou as dependências identificadas.

## Links

Inclua links para `issues`, `pull requests`, documentos, evidências ou ADRs relacionados.
