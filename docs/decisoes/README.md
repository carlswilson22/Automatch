# Decisões

Esta pasta concentra os ADRs (Architectural Decision Records) do repositório. Use esses registros para documentar as decisões relevantes do projeto, com contexto, escolha feita e impacto esperado.

Crie um novo ADR sempre que uma decisão alterar escopo, processo, arquitetura, integração, critério avaliativo ou qualquer outro ponto que precise de histórico consultável.
